अपलोड करने का तरीका (सावधानी से):
1. पहले index.html अपलोड करें — इससे homepage वापस ठीक हो जाएगा।
2. फिर बाकी 30 .html files (gallstones.html, tonsillitis.html ...) उसी मुख्य folder में अपलोड करें
   जहाँ dengue.html रखी है।
3. कोई folder अपलोड न करें। पिछली बार वाले 30 folders (अगर बने हों) हटा सकते हैं।
4. sitemap-new-pages.xml के <url> वाले हिस्से अपने sitemap.xml में जोड़ें — यह file अलग से अपलोड करना ज़रूरी नहीं।
